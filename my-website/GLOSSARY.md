# 个人网站

站主向访客展示的公开内容，以及站主登录后才处理的作品简介。

## Language

**访客**:
没有登录的阅读者。
_Avoid_: 用户, 账号

**管理员**:
站主本人的登录身份。
_Avoid_: 招聘账号, 访客

**招聘账号**:
交给招聘方阅读 Project 的登录身份。全站只有一个。
_Avoid_: 管理员, 访客, 用户

**Profile（简介）**:
全站唯一的一段公开短介绍，说明站主是谁、现在在做什么。
_Avoid_: 我的, 关于, 账号

**Project（项目）**:
站主对自己做过或正在做的一件作品所写的简介。
_Avoid_: 待办, 博客, 链荐

**链荐**:
站主写下的一条公开推荐，带有一个链接。
_Avoid_: 推荐, 收藏, 刷新项

**刷新项**:
热点、音乐、书籍或文章中的一条。内容来自外部来源，访客可以刷新以看到另一批。
_Avoid_: 推荐, 链荐, 收藏

**助手**:
站上留给站主自己部署的大模型的入口。
_Avoid_: 客服, 问答机器人, 直答
